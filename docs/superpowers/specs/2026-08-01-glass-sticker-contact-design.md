# 玻璃贴纸联系尾屏设计

## 目标

将首页最后区域当前的人物头像 `imag/xuhao-main-avatar.webp` 替换为参考 `haoqi.design` 最后一屏风格的互动尾屏：蓝色玻璃舞台、玻璃质感大字，以及从上方掉落并可被指针推动/拖拽的抽象玻璃贴纸。

## 范围

- 只修改首页最后的 `featured-second-screen` 相关展示层、样式和交互脚本。
- 保留现有联系信息、微信名片触发、导航锚点和其他页面模块。
- 不修改 `src/chat/`、`src/admin/`、`src/bootstrap.jsx` 以及无关的页面交互。
- 贴纸素材使用新生成的透明 WebP/PNG，不复用现有工具 Logo。

## 视觉设计

- 舞台采用深蓝到亮蓝的渐变，叠加低强度径向光晕和轻微玻璃高光。
- 中央标题保留个人识别文字，使用大号粗体、冷白到浅蓝渐变、半透明高光和柔和投影，模拟玻璃/液态塑料效果。
- 生成 8–12 个抽象玻璃贴纸，形状包含圆角块、弯曲条、圆环和液态字母碎片；每个贴纸具有不同尺寸、透明度、色相和初始旋转角。
- 贴纸从视口上方分批进入，避免首次加载时同时出现造成闪烁。

## 交互设计

- 贴纸由轻量 JavaScript 物理循环驱动：重力、阻尼、旋转、边界回弹和贴纸间的简化碰撞。
- 指针移动到舞台内时，对附近贴纸施加短距离排斥力，形成被鼠标推开的效果。
- 鼠标或触摸按住贴纸即可拖动；释放后贴纸恢复重力运动。
- 动画仅在尾屏接近视口或进入视口后启动，并在离开视口时暂停，降低 CPU 占用。
- `prefers-reduced-motion: reduce` 下关闭自由掉落和持续漂移，仅保留静态玻璃贴纸与淡入。

## 响应式与可用性

- 桌面端使用完整贴纸数量和较明显的位移/旋转。
- 移动端减少贴纸数量、缩小碰撞半径并限制最大速度，保证触摸操作和滚动稳定。
- 贴纸为装饰性元素，设置 `aria-hidden="true"`，不阻断联系信息和导航操作。
- 继续保留底部微信按钮、邮箱、电话和位置内容的可点击性。

## 实现边界

- 优先使用 DOM/CSS 贴纸与 JavaScript 物理模拟，不引入 Three.js/WebGL 依赖。
- 新增一个尾屏交互模块，避免继续扩大已有 Logo 物理脚本的职责。
- 生成素材后先检查透明背景、尺寸和移动端裁切，再接入页面。

## 验证标准

- 首页最后区域不再显示人物头像。
- 进入尾屏后能看到玻璃大字和抽象玻璃贴纸。
- 贴纸能从顶部掉落，鼠标/触摸可以推动和拖拽。
- 微信名片和现有联系信息仍可用。
- 桌面端和移动端不出现横向溢出或明显掉帧。
- `npm run build` 通过。
